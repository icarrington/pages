Cyber Pandemic Defense Checklist

One-page quick-reference — work top to bottom, check off each item

Priority Critical High Medium

Backups

Critical
  • 3 copies of important data
  • On 2 different storage types
  • 1 copy offsite
  • Keep one offline / air-gapped drive (unplugged)
  • Backup is automated
  • Restore tested at least once in last 6 months

The offline drive is your ransomware insurance.

Account Security

Critical
  • Use a password manager
  • Unique password for every account
  • MFA on email
  • MFA on cloud storage
  • MFA uses authenticator app or hardware key (NOT SMS)
  • MFA backup codes saved offline
  • MFA on banking

SMS MFA is SIM-swappable — use apps or keys instead.

Updates & Patching

High
  • OS auto-update ON
  • Browser auto-update ON
  • Router firmware up to date
  • Router default admin password changed
  • Server / IoT on separate network or VLAN
  • Antivirus / Defender active

Network Isolation

High
  • Guest Wi-Fi for IoT devices
  • IoT NOT on main network
  • Dedicated profile / machine for risky browsing
  • Not running as admin on daily machine
  • Firewall enabled
  • USB auto-run disabled

Incident Response

Critical
  • Written list of where recovery drives are stored
  • MFA backup codes location noted offline
  • Email provider recovery contacts saved
  • Cloud storage recovery contacts saved
  • ISP support number saved
  • Know how to kill the network (unplug / Wi-Fi off)
  • Know which device is the router and how to reboot it
  • Have a clean USB recovery stick

When compromised: unplug → don't panic-sell → isolate → assess.

Threat Awareness

Medium
  • Bookmark CISA.gov / national CERT
  • Subscribe to reputable security newsletter
  • Know scam #1: "Your account is compromised, click here"
  • Know scam #2: "Free virus removal / tech support"
  • Rule: never click — go to site directly
  • Verify unexpected urgent emails by calling
  • Don't reuse passwords across unrelated services

The 4 things that stop 80% of the pain: Offline backup + Authenticator-app MFA + Password manager + Auto-updates
